# i18n 自动扫描脚本 — 架构设计

## 文件结构

```
scripts/i18n-scan/
  index.cjs              # CLI 入口，串联全流程
  config.cjs             # 配置加载 + 默认值合并
  scanner.cjs            # 文件扫描（fast-glob）
  parsers/
    vue-sfc-parser.cjs   # 解析 .vue 单文件组件
    template-parser.cjs  # 解析 Vue 模板 AST（@vue/compiler-dom）
    script-parser.cjs    # 解析 JS/TS AST（@babel/parser + traverse）
  transformers/
    template-transformer.cjs  # 替换模板中的中文
    script-transformer.cjs    # 替换脚本中的中文
  generators/
    key-generator.cjs    # 中文 → 驼峰英文 key
    module-classifier.cjs # 按模块分类（common/form/validation/table/message）
    locale-manager.cjs   # 读写合并 locale JSON 文件
  utils/
    chinese-detector.cjs # 中文检测（正则）
    logger.cjs           # 日志输出
```

## 执行流程

```
加载配置 → 扫描文件 → 逐文件解析 → 生成 key → 执行替换 → 写 locale 文件 → 输出日志
```

### 1. 加载配置
- 读取 `i18n.config.js`，合并默认值
- 支持命令行 `--config` 指定配置文件

### 2. 扫描文件
- 使用 `fast-glob` 匹配 `entry` 模式
- 排除 `exclude` 列表和 `node_modules`、`dist`

### 3. 逐文件解析

**Vue SFC 文件**（`.vue`）：
1. `@vue/compiler-sfc` 拆分为 template / script setup / script
2. Template 用 `@vue/compiler-dom` 解析 AST，遍历节点找中文
3. Script 用 `@babel/parser` 解析 AST，遍历节点找中文

**纯 JS/TS 文件**：
- 直接用 `@babel/parser` 解析

### 4. 生成 Key

1. 优先查内置映射表（100+ 常用词汇）
2. 其次查现有 locale 反向映射（中文 → 英文 key）
3. 兜底用 hash 生成（正常情况下不会触发）

### 5. 执行替换

- 使用字符串切片（从后往前替换，避免偏移量变化）
- 静态属性 `label="xxx"` → `:label="$t('key')"`
- 文本内容 → `{{ $t('key') }}`
- 脚本字符串 → `$t('key')`

### 6. 写 Locale 文件

- 读取现有 JSON，合并新 key（不覆盖已有翻译）
- 按模块嵌套结构写入
- 为目标语言生成骨架

## 依赖的 npm 包

| 包名 | 用途 | 来源 |
|------|------|------|
| `@vue/compiler-sfc` | 解析 .vue 文件 | vue 的间接依赖 |
| `@vue/compiler-dom` | 解析 Vue 模板 AST | vue 的间接依赖 |
| `@babel/parser` | 解析 JS/TS AST | 项目已有 |
| `@babel/traverse` | 遍历 AST 节点 | 项目已有 |
| `@babel/types` | AST 节点类型判断 | 项目已有 |
| `fast-glob` | 文件匹配 | 项目已有 |
| `magic-string` | 源码替换（预留） | 项目已有 |

所有依赖均为项目已有包，无需额外安装。

## 为什么用 .cjs 扩展名

项目 `package.json` 中 `"type": "module"`，`.js` 文件会被当作 ESM。脚本使用 CommonJS（`require`），所以用 `.cjs` 扩展名。

## Key 生成优先级

```
内置映射表（builtinMap） > 现有 locale 反向映射 > hash 兜底
```

内置映射表优先于反向映射，因为内置映射的 key 更短更语义化。例如：
- 内置映射：`基本信息` → `basicInfo`
- 反向映射：`基本信息` → `basicInformation`（从旧 locale 的 "Basic Information" 转来）
