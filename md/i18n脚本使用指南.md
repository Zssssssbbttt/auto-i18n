# i18n 自动扫描脚本 — 使用指南

## 快速开始

```bash
# 预览模式（不修改任何文件，仅查看将要改什么）
node scripts/i18n-scan/index.cjs -d

# 执行扫描和替换
node scripts/i18n-scan/index.cjs -s

# 交互模式（一步步引导完成全流程）
node scripts/i18n-scan/index.cjs
```

## 命令行参数

| 参数 | 简写 | 说明 |
|------|------|------|
| 无参数 | — | 交互模式：配置向导 → 依赖检查 → 初始化 → AI翻译(可选) → 预览 → 替换 |
| `--all` | `-a` | 全流程：依赖检查 → init → translate → scan |
| `--init` | `-i` | 初始化 locales 目录结构，更新 main.ts |
| `--translate` | `-t` | AI 翻译（扫描中文 → 去重 → 调 API → 写回语言包） |
| `--scan` | `-s` | 执行替换（修改源文件 + 更新语言包） |
| `--dry-run` | `-d` | 预览模式，只输出不修改文件 |
| `--gap` | `-g` | 盲区扫描（输出所有中文，不受配置白名单限制） |

## 配置文件 `i18n.config.js`

项目根目录下的 `i18n.config.js`，完整配置项：

```js
export default {
  // 项目根目录路径（相对于本配置文件的路径）
  projectPath: './program/vue3-fundTransfer',

  // 扫描范围（glob 模式）
  entry: ['src/**/*.{vue,js,ts,jsx,tsx}'],

  // 排除文件
  exclude: ['src/router.ts'],

  // 是否扫描 <script> 中的中文
  scanScript: false,

  // 是否替换变量声明赋值中的中文
  scanScriptDeclarations: false,

  // UI 组件库（element-plus / vant / none）
  // 影响生成的 locales/index.ts 模板和 translateMethods 默认值
  uiLibrary: 'element-plus',

  // 共享语言包路径（相对于 projectPath）
  // 初始化时会将指定目录下的语言文件 import 并深度合并到 i18n 实例的 messages 中
  // 当前项目自身的翻译优先级高于共享语言包（项目覆盖共享）
  sharedLocales: [],

  // locale 文件输出目录
  output: 'src/locales',

  // 项目源码根目录
  baseDir: 'src',

  // 源码中的语言（作为 key 来源）
  sourceLanguage: 'zh-CN',

  // 要生成骨架的其他语言（添加泰语: ['en', 'th']）
  targetLanguages: ['en'],

  // localStorage 中存储语言设置的 key
  localeStorageKey: 'ZXY_locale',

  // 需要翻译的 HTML 属性（白名单）
  translateAttributes: [
    'label', 'placeholder', 'title', 'title-info', 'alt',
    'message', 'content', 'desc', 'text', 'header', 'menuTitle',
  ],

  // 永远不翻译的属性（黑名单，优先级高于白名单）
  ignoreAttributes: [
    'style', 'class', 'ref', 'rules', 'model', 'prop',
    'key', 'slot', 'name', 'id', 'type', 'format',
    'value-format', 'range-separator', 'prefix-icon', 'suffix-icon',
    'scoped', 'lang', 'src', 'href', 'target', 'width', 'size',
    'mode', 'disabled', 'clearable', 'filterable', 'remote',
    'reserve-keyword', 'multiple', 'show-overflow-tooltip',
    'align', 'maxlength', 'rows', 'trigger', 'icon',
  ],

  // 需要翻译的方法调用（白名单，支持通配符如 ElMessage.*）
  translateMethods: [
    'ElMessage.*', 'ElMessageBox.*', 'ElNotification.*', 'alert', 'confirm',
  ],

  // key 命名风格
  keyStyle: 'camelCase',

  // 日志输出目录
  logDir: 'logs',

  // AI 翻译配置
  ai: {
    enabled: true,

    // 参考语言包路径，翻译时优先复用已有翻译
    referenceLocales: [],

    // OpenAI 兼容 API 配置
    apiKey: 'sk-xxx',
    baseURL: 'https://api.openai.com/v1',
    model: 'gpt-4o',
    temperature: 0.3,
    maxTokens: 200000,

    // 每批最多翻译条数
    batchSize: 200,
  },
}
```

## 添加新语言

1. 在 `i18n.config.js` 的 `targetLanguages` 中添加语言代码：
   ```js
   targetLanguages: ['en', 'th']  // 添加泰语
   ```

2. 运行 `node scripts/i18n-scan/index.cjs -i`，会自动生成 `src/locales/th.json` 骨架文件

3. 手动翻译 `th.json` 中的空字符串

## 共享语言包

多个项目可以共享一套公共语言包，避免重复翻译。配置 `sharedLocales` 后，初始化时会将共享包 import 并深度合并到 i18n 实例中。

```js
// i18n.config.js
sharedLocales: ['../common-locales']
```

**目录结构**（与项目自身 locales 结构一致）：

```
common-locales/
  zh-CN.json
  en.json
```

**合并规则**：
- 深度合并，同模块下的 key 不会互相覆盖
- 当前项目翻译优先级高于共享包（项目覆盖共享）
- 共享包校验不通过时，交互模式会询问是否继续（跳过共享包），非交互模式自动跳过

**示例**：

```js
// 共享包 zh-CN.json
{ "common": { "confirm": "确认", "startTime": "开始时间" } }

// 项目 zh-CN.json
{ "common": { "confirm": "确定" } }

// 合并结果
{ "common": { "confirm": "确定", "startTime": "开始时间" } }
```

## 模板替换规则

| 原始写法 | 替换后 |
|---------|--------|
| `label="申请人"` | `:label="$t('form.applicant')"` |
| `placeholder="请选择"` | `:placeholder="$t('common.pleaseSelect')"` |
| `<el-button>发起申请</el-button>` | `<el-button>{{ $t('common.createApplication') }}</el-button>` |
| `ElMessage.warning('金额不能超过原始金额')` | `ElMessage.warning($t('validation.amountExceed'))` |
| `message: '请选择申请人'` | `message: $t('validation.pleaseSelectApplicant')` |

## 初始化对 main.ts 的修改

执行 `-i` 或 `--all` 时，脚本会自动修改 `src/main.ts`，插入以下内容：

```ts
import { setI18nInstance, getComponentMessages } from '@vnet/i18n'
import i18n, { $t } from './locales'

const app = createApp(App)

// 全局注册 $t，模板中可直接使用
app.config.globalProperties.$t = $t

// 将公共组件词条合并到当前 i18n 实例，并注册到 @vnet/i18n，
// 使 FlowProcess 等公共组件能随项目语言切换
const compMsgs = getComponentMessages()
for (const locale of Object.keys(compMsgs)) {
  i18n.global.mergeLocaleMessage(locale, compMsgs[locale])
}
setI18nInstance(i18n)

app.use(i18n).mount('#app')
```

每项插入都有去重检测，已存在的不会重复添加。

## 注意事项

1. **先 dry-run**：执行 `node scripts/i18n-scan/index.cjs -d` 预览所有改动，确认无误后再 `-s` 执行替换
2. **$t 全局可用**：`main.ts` 中已全局注册 `$t`，模板和脚本中直接使用，无需 import
3. **语言切换**：`App.vue` 使用 vue-i18n 的 `locale` 响应式切换，无需手动刷新页面
4. **日志**：每次扫描会在 `logs/` 目录生成 JSON 日志文件，记录所有改动
